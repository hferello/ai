# Communication Prompts

A collection of ready-to-use AI prompts for communication, personal branding, and content creation. Most are coaching prompts that interview you first, then draft a tailored message using a specific, well-known framework. A few are standalone tools for building content or pages.

## How to use these

Most prompts are self-contained. Open the file, copy the whole thing (including the instructions at the top), and paste it into your AI assistant as-is; don't fill anything in yourself first. The assistant will ask you questions one at a time, then use your answers to write the final message. Prompts that need variables filled in first (like the landing page prompt) say so explicitly.

## Choosing the right prompt

- **Sharing information or making a request/recommendation** use `get-to-the-point-prompt.md`
- **Same message, different audiences** use `audience-adaptation-prompt.md` (supports adapting one message for multiple audiences at once)
- **Making an ask land more persuasively** use `principles-of-influence-prompt.md`, layered on top of whichever framing prompt you're already using
- **Difficult conversation with a person** use `corrective-feedback-prompt.md`, `saying-no-prompt.md`, or `disagreeing-with-senior-prompt.md`
- **Announcing something to a group** use `communicating-change-prompt.md`
- **Keeping stakeholders in the loop on a project** use `stakeholder-update-template-prompt.md`
- **Prepping questions before a meeting** use `asking-good-questions-prompt.md`
- **Presenting numbers or findings** use `data-storytelling-prompt.md`
- **Polishing a message so it's remembered** use `make-it-stick-prompt.md` (works well as a final pass after any of the above)
- **Networking or unstructured social settings** use `small-talk-practice-prompt.md` or `headliner-and-connect-back-prompt.md`
- **Rehearsing a high-stakes ask before the real thing** use `negotiation-practice-prompt.md`
- **Writing an actual negotiation email** use `negotiation-email-prompt.md`
- **Figuring out or shaping how you come across** use `communication-qualities-analysis-prompt.md` to diagnose, then `communication-brand-prompt.md` to build a plan
