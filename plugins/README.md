# Claude Plugins Packaging

This directory contains Claude Code plugin wrappers for the root skills in this repo.

## Single source of truth

Edit the root skill folders only:

- `context/`
- `feature/`

Do not manually edit generated copies under `plugins/*/skills/*`.

## Generated vs curated files

Generated by `scripts/build-claude-plugins.sh`:

- `plugins/context/skills/context/**`
- `plugins/feature/skills/feature/**`

Curated (manually maintained):

- `plugins/context/.claude-plugin/plugin.json`
- `plugins/feature/.claude-plugin/plugin.json`
- `plugins/feature/hooks/hooks.json`
- `plugins/feature/hooks/planning-reminder.sh`
- `plugins/feature/hooks/planning-check-complete.sh`
- `.claude-plugin/marketplace.json`

## Regenerate after skill changes

From repo root:

```bash
bash scripts/build-claude-plugins.sh
```

Then review `git diff` and commit both source changes and regenerated plugin copies together.
